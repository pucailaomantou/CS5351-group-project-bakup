# Three improvement goals (raw, from the team meeting on 2026-11-17)

## 1. Cost
A single ticker analysis burns too many tokens and takes too long.
We want it cheaper and faster without losing decision quality.

## 2. Debate quality
The bull/bear discussion is free-form; agents just talk.
We want it structured so the Research Manager can actually weigh arguments.

## 3. Safety
The agent's final decision goes straight out.
We want a boundary where the AI's output is checked by deterministic code
before anything is acted on.
